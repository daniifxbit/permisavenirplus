# Permis Avenir +

Site vitrine (landing page) pour **Permis Avenir +**, service d'accompagnement
personnalisé aux démarches du permis de conduire en France.

## Aperçu

Page unique présentant : héro, « Pourquoi nous », services par catégorie de permis
(B, A1, A2, automatique, C, D, BE), tarifs, méthode, avis clients, galerie
(attestations / témoignages), FAQ et contact WhatsApp.

## Lancer le site

Ouvrir `Permis Avenir Plus.dc.html` dans un navigateur (une connexion internet est
requise : le runtime `support.js` charge React automatiquement).

## Structure

```
Permis Avenir Plus.dc.html   Page (template + données)
support.js                   Runtime (charge React et amorce la page)
assets/                      Images : héro, avis, galerie, attestations, logo
```
